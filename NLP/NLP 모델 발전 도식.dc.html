01  RNN

Elman, Finding Structure in Time (1990) · 하나의 셀을 시점마다 반복 사용합니다.

나는 ↓ RNN ↓ h₁
h₁ →
영화를 ↓ RNN ↓ h₂
h₂ →
좋아한다 ↓ RNN ↓ h₃
같은 셀, 같은 파라미터를 매 시점 다시 사용합니다.
입력 / 출력
입력: 토큰 임베딩 xₜ 하나씩
출력: 시점별 hidden state hₜ
내부 상태
hidden state hₜ 하나. 지금까지 읽은 내용을 담은 유일한 기억입니다.
hₜ = tanh( W_x·xₜ + W_h·hₜ₋₁ + b )
yₜ = softmax( W_o·hₜ )
작은 예시 · h₁ = [0.4, −0.2] 에 “영화를”이 들어오면 h₂ = tanh(W_x·x₂ + W_h·[0.4, −0.2]) = [0.7, 0.1]. 새 입력과 이전 기억이 한 번의 tanh로 섞입니다.
유지
토큰 임베딩 입력
추가
순환 연결 hₜ₋₁ → hₜ
제거
없음 (출발점)
다음 모델이 해결한 한계
기억이 hₜ 하나라서 매 시점 덮어쓰입니다. 문장이 길어지면 역전파 과정에서 기울기가 소실되어 앞부분 정보가 사라집니다. → LSTM이 별도의 기억 통로를 만듭니다.

02  LSTM

Hochreiter & Schmidhuber, Long Short-Term Memory (1997) · RNN의 hidden state 계산만 바꾼 셀입니다.

LSTM CELL
forget f = 0.9 input i = 0.2 output o = 0.7
f가 1에 가까우면 옛 기억을 그대로 통과시킵니다. 이 곱셈 경로가 기울기 소실을 완화합니다.
→
cₜ hₜ
입력 / 출력
입력: xₜ, hₜ₋₁, cₜ₋₁
출력: hₜ, cₜ
내부 상태
기억 통로 cₜ(점선)와 밖으로 내보내는 hₜ(검은 채움), 두 갈래로 분리됩니다.
f, i, o = σ( W·[hₜ₋₁, xₜ] + b )
g̃ = tanh( W_g·[hₜ₋₁, xₜ] + b_g )
cₜ = f ⊙ cₜ₋₁ + i ⊙ g̃
hₜ = o ⊙ tanh( cₜ )
작은 예시 · cₜ₋₁ = 1.0 에서 f = 0.9, i = 0.2, g̃ = 0.5 이면 cₜ = 0.9×1.0 + 0.2×0.5 = 0.95. 옛 기억의 대부분이 살아남습니다.
유지
순차 처리, hₜ 전달 방식
추가
cell state, forget·input·output gate
제거
단일 tanh 갱신
다음 모델이 해결한 한계
LSTM은 셀일 뿐이어서, 입력 4토큰을 읽고 출력 5토큰을 만드는 번역처럼 길이가 다른 작업을 담을 구조가 없습니다. → Seq2Seq가 역할을 둘로 나눕니다.

03  Seq2Seq

Encoder
I h₁ → love h₂ → this h₃ → movie h₄
h₁–h₃은 버리고 마지막 h₄만 넘깁니다.
c = h₄enc
고정 길이 context vector
Decoder
<BOS> → 나는 → 이 → 영화를 → 좋아한다
c를 s₀으로 받아 같은 셀을 반복 사용합니다. 시점마다 새 Decoder가 생기는 것이 아니라, 들어가는 이전 토큰과 상태만 바뀝니다.
다음 토큰은 어휘 집합 전체의 확률에서 고릅니다

추가

05  Transformer

Vaswani et al., Attention Is All You Need (2017) Figure 1–2 · 역할(Encoder·Decoder)은 그대로 두고, 그 역할을 수행하는 내부 부품을 LSTM에서 Attention 블록으로 교체했습니다.

Self-Attention 계산 흐름
X = 토큰 임베딩 + positional encoding → Q = XWQ K = XWK V = XWV → QKᵀ → ÷ √d_k → softmax → V 가중합 → Z · 문맥이 반영된 출력
LSTM의 반복 계산이 사라져 토큰 순서를 알 수 없으므로 positional encoding을 더합니다. 모든 토큰이 다른 모든 토큰을 한 번에 직접 참고합니다.

Cross-Attention의 Q는 Decoder 표현, K와 V는 Encoder 출력입니다. Bahdanau Attention과 같은 일을 Q·K·V 행렬 곱으로 합니다.

<BOS> → 나는 → 나는 이 → 나는 이 영화를 → … → <EOS>

06  BERT / GPT

같은 Transformer 블록에서 목적에 따라 갈라진 두 계열입니다.

BERT
Transformer Encoder 계열 · Devlin et al. 2018
토큰 + segment + position embedding
→ 양방향 Self-Attention Encoder 블록 ×L
→ 각 토큰의 문맥 표현 H
→ [MASK] 자리 복원 또는 분류 헤드
각 토큰이 왼쪽과 오른쪽을 모두 참고합니다. Masked Language Modeling으로 사전학습하고, 문장 분류·토큰 분류·질의응답에 fine-tuning합니다. 기본 BERT에는 생성용 Decoder가 없습니다.
H⁽ˡ⁾ = EncoderBlock( H⁽ˡ⁻¹⁾ )
P(x_masked) = softmax( W·h_[MASK] )
나는 이 영화를 [MASK] → 좋아한다 0.71
GPT
Causal Decoder 계열 · Improving Language Understanding by Generative Pre-Training
토큰 embedding + position
→ Causal Self-Attention
→ Feed-Forward Network  (×L층 반복)
→ Vocabulary Linear layer
→ softmax → 다음 토큰 선택
→ 고른 토큰을 입력 뒤에 붙여 반복
번역용 Decoder에 있던 Encoder–Decoder Cross-Attention은 없습니다. 참고할 입력이 따로 있는 것이 아니라, 지금까지의 출력 자체가 입력입니다.
H⁽ˡ⁾ = DecoderBlock( H⁽ˡ⁻¹⁾, causal mask )
logits = W_vocab · h_t
P(y_t₊₁ | y≤t) = softmax(logits)
나는 이 영화를 → 좋아한다 0.62 / 싫어한다 0.21 / 봤다 0.11
정리
RNN·LSTM은 계산 부품, Seq2Seq는 구성 방식, Attention은 계산 장치, Transformer는 그 장치로 Encoder와 Decoder를 구현한 구조, BERT와 GPT는 그 구조를 어느 쪽으로 쌓았는지의 차이입니다.
